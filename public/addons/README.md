# Фото додаткових послуг («Додайте до свята»)

Покладіть сюди фото з такими назвами (jpg / jpeg / png / webp) — сайт
підхопить їх автоматично, і плитка переміститься в перший ряд (з фото):

| Файл                | Послуга                     |
| ------------------- | --------------------------- |
| `pinata.jpg`        | Піньята-сюрприз             |
| `pinata-custom.jpg` | Піньята під замовлення      |
| `pinata-own.jpg`    | Своя піньята                |
| `animator.jpg`      | Аніматор                    |
| `photographer.jpg`  | Професійний фотограф        |
| `cake.jpg`          | Святковий торт              |
| `merch.jpg`         | Мерч нашої компанії         |
| `arena.jpg`         | Індивідуальне закриття арени|

Фото, завантажене через CRM (Розваги і ціни → Додаткові послуги),
має пріоритет над файлом звідси. Рекомендований формат — горизонтальний,
приблизно 2:1 (наприклад 800×400), до 5 МБ.

Для послуг, створених через CRM (кнопка «+ Нова послуга»), фото
завантажується лише через CRM — файлової назви в них немає.
